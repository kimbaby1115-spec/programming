# 📚 북로그 (BookLog) - 나만의 독서 기록 관리 서비스

읽고 있는 책과 완독한 책을 상태별로 분류하고 감상평을 관리할 수 있는 개인 독서 기록 웹 애플리케이션입니다.

## 1. 이번 주 추가·수정한 주요 기능
- **시맨틱 내비게이션 및 라우팅 구현**: `<nav>`와 `<ul>`·`<li>` 구조로 주요 메뉴를 구성하고 해시 라우팅(`#/home`, `#/add`, `#/list`)을 연결했습니다.
- **현재 위치 표시 및 웹 접근성 강화**: 현재 활성화된 메뉴에 시각적 강조 스타일과 `aria-current="page"`를 적용했으며, 새로고침 및 브라우저 뒤로 가기 시에도 상태가 일치하도록 구현했습니다.
- **목록 필터링 및 결과 안내 고도화**: 상태별 필터 버튼에 `aria-pressed` 상태를 반영하고, 현재 필터링된 도서 수를 실시간으로 안내합니다. 또한 전체 데이터가 없는 경우와 선택한 필터 조건에 해당하는 데이터만 없는 경우를 구분해 안내 문구를 표시합니다.
- **반응형 모바일 메뉴 구현**: 화면 폭 `768px` 이하에서 `메뉴 열기`/`메뉴 닫기` 버튼(`aria-expanded` 연동)으로 메뉴를 펼치고 접을 수 있으며, 목적지 선택 시 자동으로 메뉴가 닫히도록 개선했습니다.

## 2. 메뉴별 목적지 안내

| 메뉴 이름 | 경로 (Hash) | 목적지 및 주요 기능 |
| :--- | :--- | :--- |
| **서비스 소개** | `#/home` | 서비스 개요 안내 및 전체·읽는 중·완독 도서 요약 통계 확인 |
| **독서 기록 추가** | `#/add` | 도서명, 저자, 진행 상태, 감상평을 입력하여 `localStorage`에 저장 |
| **내 서재 목록** | `#/list` | 등록된 도서 목록 조회, 진행 상태별 필터링, 도서 상세 보기 및 삭제 |

## 3. 목록 필터 기준
- **전체 (`all`)**: 서재에 등록된 모든 도서를 표시합니다.
- **읽는 중 (`reading`)**: 현재 독서를 진행 중인 도서만 표시합니다.
- **완독 (`completed`)**: 끝까지 읽기를 마친 도서만 표시합니다.
- **읽고 싶음 (`wishlist`)**: 앞으로 읽을 예정인 도서만 표시합니다.

## 4. 기능 확인 조작 순서 (테스트 시나리오)
1. **메뉴 이동 및 현재 위치 확인**: 상단 메뉴(`서비스 소개` → `독서 기록 추가` → `내 서재 목록`)를 클릭하며 메뉴 강조 표시와 브라우저 뒤로 가기·새로고침 시 위치 일치를 확인합니다.
2. **주요 기능(입력 및 저장) 이용**: `독서 기록 추가` 메뉴에서 새 책 제목, 저자, 상태(`읽고 싶음` 등)를 입력한 뒤 `서재에 저장하기`를 눌러 목록 페이지로 자동 이동되는지 확인합니다.
3. **결과 목록 및 상세 보기 확인**: `내 서재 목록`에서 방금 추가한 도서를 확인하고 `상세 보기` 버튼을 눌러 감상평과 삭제 기능을 테스트합니다.
4. **필터 및 빈 결과 안내 확인**: `전체`, `읽는 중`, `완독`, `읽고 싶음` 필터 버튼을 차례로 눌러 결과 권수와 목록 변경을 확인합니다. 항목이 0개인 필터 선택 시 조건 불일치 안내가 나오는지, 모든 도서를 삭제했을 때는 전체 목록 없음 안내가 나오는지 확인합니다.
5. **모바일 화면 동작 확인**: 브라우저 개발자 도구(F12)에서 화면 폭을 `375px`로 줄인 뒤 `메뉴 열기` 버튼을 눌러 메뉴를 펼치고, 항목 선택 시 메뉴가 자동으로 닫히는지 확인합니다.
