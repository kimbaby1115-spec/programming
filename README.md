# 📚 BookLog - 독서 기록 및 인사이트 관리 서비스

독서 상태(읽는 중, 완독, 읽고 싶은 책)별로 책과 핵심 문장을 기록하고, 독서 통계를 한눈에 확인할 수 있는 웹 서비스입니다.

- **GitHub 저장소 주소:** `https://github.com`
- **GitHub Pages 배포 주소:** `https://github.io`

---

## 1. 이번 주 추가·수정한 주요 기능
1. **서비스 맞춤형 내비게이션 구성 (`nav > ul > li`)**
   - 독서 기록 서비스의 흐름에 맞춰 주요 메뉴 3가지를 시맨틱 마크업으로 구성했습니다.
2. **현재 위치 표시 및 브라우저 히스토리 연동 (`aria-current`)**
   - 현재 보고 있는 메뉴에 시각적 강조 스타일과 `aria-current="page"` 속성을 부여하고, 다른 메뉴에서는 제거합니다.
   - 메뉴 클릭 이동, 페이지 새로고침, 브라우저 뒤로 가기(`popstate`) 및 스크롤 이동 시에도 현재 위치 표시가 실제 화면과 일치합니다.
3. **독서 상태별 목록 필터 및 결과 안내 (`aria-pressed`)**
   - `전체`, `읽는 중`, `완독`, `읽고 싶은 책` 4가지 필터 버튼을 구현하고, 선택 상태를 `aria-pressed` 속성과 스타일에 반영했습니다.
   - 현재 표시되는 기록 건수를 실시간으로 안내하며, **전체 기록이 없는 경우**와 **선택한 필터 조건에 맞는 결과만 없는 경우**를 구분하여 안내 문구를 표시합니다.
4. **반응형 모바일 내비게이션 메뉴 (`aria-expanded`)**
   - 화면 너비 `768px` 이하에서는 `메뉴 열기`/`메뉴 닫기` 버튼을 통해 메뉴를 펼치고 접을 수 있으며, `aria-expanded` 속성과 버튼 문구가 함께 변경됩니다.
   - 메뉴 항목을 선택하면 해당 영역으로 스크롤 이동한 뒤 펼쳐진 모바일 메뉴가 자동으로 닫힙니다.
5. **기존 기록 작성·저장·상세 보기 기능 유지**
   - `localStorage`를 통한 독서 기록 추가, 상세 보기 모달 확인, 개별 삭제 및 전체 비우기 기능을 유지했습니다.

## 2. 메뉴별 목적지 안내

| 메뉴 이름 | 연결 목적지 (`id`) | 설명 |
| :--- | :--- | :--- |
| **독서 기록 작성** | `#record-section` | 도서명, 저자, 독서 상태, 평점, 핵심 메모를 입력하고 저장하는 영역 |
| **내 서재 목록** | `#list-section` | 저장된 독서 기록을 상태별 필터로 조회하고 상세 내용을 확인하는 영역 |
| **독서 통계 요약** | `#stats-section` | 전체, 완독, 읽는 중, 읽고 싶은 책 권수를 한눈에 집계하여 보여주는 영역 |

---

## 3. 목록 필터 기준
- **전체 (`all`)**: 저장된 모든 독서 기록을 표시합니다.
- **읽는 중 (`reading`)**: 현재 독서를 진행 중인 도서 기록만 필터링하여 표시합니다.
- **완독 (`completed`)**: 끝까지 읽기를 완료한 도서 기록만 필터링하여 표시합니다.
- **읽고 싶은 책 (`wishlist`)**: 앞으로 읽을 예정으로 등록한 도서 기록만 필터링하여 표시합니다.

## 4. 기능 확인 조작 순서
1. **메뉴 이동 및 현재 위치 확인**: 상단 내비게이션에서 `내 서재 목록`, `독서 통계 요약`을 차례로 클릭해 화면 이동과 메뉴 강조(`aria-current="page"`) 변화를 확인합니다. 브라우저의 **뒤로 가기**와 **새로고침**을 눌러도 위치 표시가 유지되는지 확인합니다.
2. **주요 기능(입력 및 저장) 이용**: `독서 기록 작성` 메뉴로 이동해 새 책 정보와 메모를 입력한 뒤 `기록 저장하기` 버튼을 누릅니다. 저장 직후 `내 서재 목록`으로 자동 이동하며 새 카드가 추가됩니다.
3. **결과 목록 및 상세 보기 확인**: 추가된 도서 카드의 `상세 보기` 버튼을 눌러 모달 창에서 전체 메모와 평점을 확인하고 닫습니다.
4. **필터 선택 및 빈 목록 분기 확인**: `읽는 중`, `완독`, `읽고 싶은 책` 필터 버튼을 눌러 항목 수 안내와 목록이 바뀌는지 확인합니다. 우측 `전체 기록 비우기`를 누르면 전체 기록 없음 안내가 출력되며, `예시 데이터 불러오기`로 다시 데이터를 복원할 수 있습니다.
5. **모바일 화면 확인**: 브라우저 개발자 도구(F12)에서 모바일 뷰(너비 375px 등)로 전환한 뒤, `메뉴 열기` 버튼을 눌러 메뉴 펼침/접힘과 목적지 선택 시 자동 닫힘 동작을 확인합니다.
