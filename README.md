# 개인 맞춤형 식단 계획 프로토타입

## 1. 서비스의 사용자 및 목적 정의 (평가기준 1)
* **주요 사용자:** 명확한 건강 목적(다이어트, 벌크업 등)을 가지고 있으나 스스로 구체적인 일일 행동 계획을 수립하는 데 어려움을 겪는 현대인.
* **목적:** 복잡한 영양학 지식 없이도 목표 기간과 타겟 체중만 입력하면 즉시 실천 가능한 하루 칼로리 통제 가이드를 제공함.
* **새 기능의 흐름 연결:** 7주차 결과물인 '건강 목적 선택' 단계의 **끝 지점**에 연결하여, 유저가 목적을 고른 직후 세부 정량 플랜을 수립하는 논리적 흐름으로 유기적 배치함.

## 2. 신규 기능 구현 및 상태 변화 기술 (평가기준 2, 3)
* **구현 기능:** '일일 칼로리 조절량 플래너' 기능. 지방 1kg당 소모 칼로리(7,700kcal) 연산 메커니즘을 적용하여 기간별 수치를 동적 가산 및 감산 처리함.
* **성공 반응:** 7주차 목적 데이터와 입력된 수치를 실시간으로 결합하여 가독성 높은 그라디언트 대시보드 배너 형태로 결과 화면 리렌더링.
* **예외/오류 피드백 분기:**
  1. **빈값 및 음수 검사:** 숫자가 아니거나 공백, 0 이하일 때 과업 연속성을 유지하도록 재입력 요구 에러 팝업 활성화.
  2. **의학적 임계치 UX 검사:** 기간 대비 체중 변화율이 하루 0.5kg을 초과하는 '극단적 수치' 입력 시 무리한 계획임을 경고하고 대안을 제안하는 똑똑한 피드백 구현.
  3. **시스템 제한 범위 검사:** 90일을 초과하는 장기 데이터 수집 제한 분기 구현.
* **값의 유지 및 초기화:** '다시 설정' 버튼 조작 시 폼 데이터 세팅 값 및 인풋을 원클릭으로 초기화하는 제어 경로 확보.

## 3. 크로스 플랫폼 조작 환경 (평가기준 4)
* 데스크톱 브라우저 환경과 모바일(스마트폰 프레임 배치 미디어 쿼리) 환경에서 입력 폼 및 하단 탭바 레이아웃이 유연하게 리플로우되도록 설계하여 컴포넌트 간 겹침 현상을 완벽히 방지함.

## 4. 시나리오 테스트 기록 (평가기준 5)
* **정상 케이스:** [다이어트 선택] -> [5kg 입력] -> [30일 입력] 제출 시 하루 `-1283 kcal` 조절 대시보드 정상 도출 및 스무스 스크롤 작동.
* **오류 분기 케이스 1:** [체중 증량 선택] -> [10kg 입력] -> [5일 입력] (무리한 단기 목표) 제출 시 *"목표 체중이 너무 무리합니다! 기한을 더 늘려주세요"* 피드백 트리거 정상 작동 확인.
* **오류 분기 케이스 2:** 인풋 공백 상태로 제출 시 0 이하 유효성 예외 처리 피드백 레이블 확인.
